# Heritage shophouse icon

Transparent stylized George Town heritage shophouse, with pastel mint walls, ornate ivory plasterwork, timber shutters and terracotta roof tiles. Master: `public/images/heritage-house-3d.png`. Optimized WebP: `public/images/heritage-house-3d.webp`.

```jsx
import HeritageHouse,{HeritageHouseLoading} from './HeritageHouse';

<HeritageHouse size={180}/>
<HeritageHouseLoading completed={false}/>
```

Included in the random project loader selection. Its color reveal opens from the center outward, suggesting shutters opening, with a soft sage glow. Completion shows full color before the shared fireworks and page reveal. Reduced-motion preferences disable animation.
