# Hindu temple loading icon

Transparent 3D miniature based on the supplied photographs, preserving the cream-and-gold stepped gopuram, grey entrance portal and paired guardian sculptures. Master: `public/images/hindu-temple-3d.png`. Optimized WebP: `public/images/hindu-temple-3d.webp`.

```jsx
import HinduTemple,{HinduTempleLoading} from './HinduTemple';

<HinduTemple size={180}/>
<HinduTempleLoading completed={false}/>
```

Included in the random project loaders. A golden color reveal rises through the stationary temple, with a subtle glow. Completion uses the shared fireworks and page reveal. Reduced-motion preferences disable animation.
