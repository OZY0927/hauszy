# Penang Hill funicular loading icon

Transparent 3D miniature based on the supplied photographs: modern blue-and-yellow carriage, inclined rails and the historic arched stone viaduct. Master: `public/images/penang-hill-3d-v2.png`. Square web-optimized asset: `public/images/penang-hill-3d-v2.webp`.

```jsx
import PenangHill,{PenangHillLoading} from './PenangHill';

<PenangHill size={200}/>
<PenangHillLoading completed={false}/>
```

Included in the random project loaders. A diagonal color sweep travels uphill from lower-right to upper-left. The train and track remain aligned as one image. Completion shows full color before the shared fireworks and page reveal. Reduced-motion mode disables animation.
