# Penang Bridge 3D icon

Transparent miniature of the first Penang Bridge, matching the Pinang tree and Komtar rendering style. Master: `public/images/penang-bridge-3d.png`. Optimized 768 × 512 WebP: `public/images/penang-bridge-3d.webp`.

```jsx
import PenangBridge,{PenangBridgeLoading} from './PenangBridge';

<PenangBridge size={240}/>
<PenangBridge size={160} decorative/>
<PenangBridgeLoading completed={false}/>
```

The bridge is included in the random project loader selection. A wavy color sweep crosses from left to right; completion reveals the full color image before the shared fireworks and page reveal. Reduced-motion settings show the static full-color icon. This is a 3D-rendered bitmap, not a mesh.
