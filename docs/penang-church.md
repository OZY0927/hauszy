# Church loading icon

Transparent 3D miniature based on the supplied St George's Church photographs, including the neoclassical columned facade, clock spire and detached round memorial pavilion. Master: `public/images/penang-church-3d.png`. Optimized WebP: `public/images/penang-church-3d.webp`.

```jsx
import PenangChurch,{PenangChurchLoading} from './PenangChurch';

<PenangChurch size={180}/>
<PenangChurchLoading completed={false}/>
```

Included in the random project loading indicators. A diagonal light sweep reveals its warm ivory color; completion uses the shared fireworks and page reveal. The architecture remains stationary, and reduced-motion preferences disable animation.
