# Floating mosque loading icon

Transparent 3D miniature based on the supplied photographs of Tanjung Bungah's blue-domed floating mosque in Penang. Master: `public/images/floating-mosque-3d.png`. Web asset: `public/images/floating-mosque-3d.webp`.

```jsx
import FloatingMosque,{FloatingMosqueLoading} from './FloatingMosque';

<FloatingMosque size={180}/>
<FloatingMosqueLoading completed={false}/>
```

The mosque is included in the random project loading indicators. Its wave-shaped color reveal and blue glow finish in full color before the shared fireworks and page reveal. The architecture stays still. Reduced-motion mode disables animation.
