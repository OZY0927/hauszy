# Kek Lok Si loading icon

Transparent 3D miniature created from the supplied photographs of the standing Guanyin statue and its tiered pavilion at Kek Lok Si, Penang. The PNG master is `public/images/kek-lok-si-3d.png`; the optimized square WebP is `public/images/kek-lok-si-3d.webp`.

```jsx
import KekLokSi,{KekLokSiLoading} from './KekLokSi';

<KekLokSi size={180}/>
<KekLokSiLoading completed={false}/>
```

The loading variant reveals color upward with a soft golden glow. The statue remains stationary. Completion shows full color before the shared fireworks and page reveal. Reduced-motion preferences disable the animation. It is included in the random project-loader selection alongside the tree, flag, Komtar and bridge.
