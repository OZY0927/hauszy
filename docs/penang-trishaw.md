# Penang trishaw loading icon

Transparent 3D icon based on the supplied reference, revised to use slimmer realistic frame, wheel and upholstery proportions rather than chunky cartoon forms. The red trishaw retains its dark canopy, yellow cushion and blue umbrella. Master: `public/images/penang-trishaw-3d.png`. Optimized WebP: `public/images/penang-trishaw-3d.webp`.

```jsx
import PenangTrishaw,{PenangTrishawLoading} from './PenangTrishaw';

<PenangTrishaw size={180}/>
<PenangTrishawLoading completed={false}/>
```

Included in the random project loader selection, with subtle rocking and a color sweep. Completion stops the motion and shows full color before the shared fireworks and page reveal. Reduced-motion preferences disable animation.
