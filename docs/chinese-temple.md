# Chinese temple loading icon

Reference-based 3D miniature with natural proportions, terracotta roofs, dragon ornaments and red lanterns. Generated using the built-in image tool.

Assets: `public/images/chinese-temple-3d.png` (master) and `public/images/chinese-temple-3d.webp` (transparent optimized 768 × 384 image).

Use `ChineseTemple` for the standalone icon or `ChineseTempleLoading` for the warm bottom-up color wave. `completed` finishes in full color; the project loading overlay supplies completion fireworks. Reduced motion displays a static icon.

Prompt: Create a refined 3D architectural miniature of the reference Chinese temple, preserving the wide two-storey red-brick facade, cream columns, veranda, red lanterns, terracotta upturned roofs and green/gold dragons. Natural proportions, restrained textures, soft studio lighting, transparent background; no people, landscape or cartoon geometry.
