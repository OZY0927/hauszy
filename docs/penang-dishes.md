# Penang dishes loading icon

Approved miniature-style preview, generated with the built-in image generator using the existing mosque and church assets as style references. The realistic photographic first preview was not selected.

Prompt: Penang char kway teow, asam laksa and cendol arranged as a compact miniature 3D still life. Match the mosque/church scale-model style: clean smooth materials, simplified fine detail, warm cream ceramic dishes, soft studio lighting and a three-quarter view. Muted terracotta, ivory, brown and green accents; genuine transparent background, no tabletop, labels or watermark.

Master: `public/images/penang-dishes-3d.png`.
Web asset: `public/images/penang-dishes-3d.webp`.
Loading asset: `public/images/loading/dishes.webp` (336px, transparent WebP).

Registered as `dishes` in `lib/project-loading-icons.js`. Uses the existing `LandmarkLoading` colour-fill and sway, plus the shared completion and centre reveal. Reduced-motion handling is unchanged.
